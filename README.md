# WhaleLife Discord 插件 0.6.1

登录失败后，插件依次等待 5、15、45 秒，最多自动重试 3 次。页首「连接状态」显示重试进度和最近一次连接错误码，页面会自动跟踪实际连接状态。点「重新连接」会立即使用已保存的配置，并重新计算重试次数。关闭连接或停用插件会取消待执行的重试。

设置页默认使用 Discord 深色外观。右上角可切换到瑞士风，选择保存在当前浏览器中。切换时仍可继续编辑未保存的表单。


鲸鲸可以在 Discord 私信、服务器文字频道和讨论串中聊天。模型与人格来自 WhaleLife。首版默认关闭连接，允许一位指定用户发私信。服务器消息可在允许的频道或讨论串里直接 @ Bot，或直接回复这个 Bot 自己的消息；可发送文字，开启识图后也可以附图。所有人共用同一频道的对话，各讨论串都有各自的历史。

## 安装

1. 准备 Node.js 24 和 WhaleLife（原图直看需要 v0.1.5 或更新版本），在网页控制台选好人格和模型，先确认网页聊天能回复。
2. 关闭 WhaleLife，在终端进入 WhaleLife 的 `plugins` 目录。首次安装时执行下面的命令，源码会放进 `plugins/discord/`，npm 根据锁文件安装运行依赖。

   ```sh
   git clone https://github.com/Tawake1/whalelife-plugin-discord.git discord
   cd discord
   npm ci --omit=dev --ignore-scripts
   ```

   也可以从仓库页面选择 **Code → Download ZIP**，解压后将含有 `plugin.yaml` 的文件夹命名为 `discord`，放入 WhaleLife 的 `plugins` 目录，再到该文件夹执行上述 npm 命令。已有独立安装包 `discord-0.6.1-install.zip` 的用户可直接解压安装，包中已带依赖。
3. 启动 WhaleLife，打开「插件管理 → Discord → 设置」。如果插件已被手动停用，先启用插件。
4. 在 [Discord Developer Portal](https://discord.com/developers/applications) 创建 Application，在 Bot 页取得 Bot Token。在 Installation 页为 Guild Install 选择 `bot` scope，使用安装链接将 Bot 加入测试服务器。可以把安装链接发给服主或有「管理服务器」权限的成员，请对方选择服务器并授权。
5. 给 Bot 授予 **View Channel、Send Messages、Read Message History**。使用讨论串时另授予 **Send Messages in Threads**，并让 Bot 能看见和进入目标讨论串。首版使用普通 Guilds、Guild Messages、Direct Messages Gateway intents；私信和显式 @ 使用默认 intents。若希望频道成员关闭回复提醒后也能发文字或图片，先在 Developer Portal → Bot → Privileged Gateway Intents 开启 Message Content Intent，再在插件设置勾选「接收回复 Bot 时未 @ 它的消息」并保存。经验证的应用可能需要 Discord 批准该意图。
6. 在 Discord「用户设置 → 高级」打开开发者模式，右键自己的用户头像、目标频道或讨论串复制 ID。进入 WhaleLife 的 Discord 设置，填写 Bot Token、选择人格，填写私信用户 ID、频道或讨论串 ID。勾选「启用 Discord 连接」，点「保存连接设置」。页首「连接状态」会自动显示登录结果。

可只使用私信或只使用服务器频道。空白的名单关闭对应入口。默认按 ID 精确匹配。开启「允许列表中父频道下的讨论串」后，插件通过 Discord 频道信息核对服务器和父频道，符合条件的讨论串可以分别聊天和暂停。Token 保存在本机插件的 `plugins/discord/data/config.json`，保存后设置页只显示是否已配置。本机资料和备份中可能含有该凭据。更换 Token 后在本页重新保存即可。

## 从旧版升级

关闭 WhaleLife，把 ZIP 解压到一个临时文件夹。打开解压后的 `discord` 文件夹，把里面的文件和目录复制到现有的 `plugins/discord/`，遇到同名文件选择覆盖。保留现有的 `data/` 文件夹（内有 Bot Token 和白名单），再启动 WhaleLife。

## 连续消息

在「插件管理 → Discord → 设置 → 消息接收」调整以下选项，点「保存连接设置」。两项默认开启，分别控制私信和频道。

- **私信：等我说完再回**。每条新的有效私信从到达时重新计时，默认 600 毫秒，可填 100 至 5000 的整数。比如设为 1200，就是你停下来 1.2 秒后开始处理。连发的文字和图片按顺序交给同一轮，先发图再补充问题也可以。关闭后逐条回复。
- **频道与讨论串：合并同一人的追发**。首条立即处理。同一人在相同频道或讨论串内连续触发鲸鲸时，仍可追加的轮次会收到补充。每条都要符合原有的白名单、@ 或回复条件。换发言人、超过宿主单轮容量或轮次已经关闭时，新开一轮。关闭选项后逐条回复。
- 宿主用每条消息自己的 Discord ID 写回执，已经接纳的追发在重启后重复投递也不会重复回答。私信静默等待期间的消息暂存在内存，关闭 WhaleLife 或重新连接会取消还在等待的消息。单独保存上述策略或等待时间可在线生效。

## Discord 图片识别

打开「插件管理 → Discord → 设置 → 图片识别」，选择图片处理方式，点「保存连接设置」。

| 图片处理方式 | 一张图发给谁 |
| --- | --- |
| 自动（优先直看） | WhaleLife v0.1.5 支持将原图随本条问题交给主聊天模型。较大的图片可交给辅助识图模型转述。如果主模型明确表示不支持图片，宿主可请求辅助模型转述本轮原图。旧版宿主使用辅助模型转述。 |
| 始终转述 | 辅助模型看图，鲸鲸收到文字观察和你的问题。需要选择支持图片的辅助模型。 |
| 关闭 | 只发图会收到设置提示，随图发送的文字仍可聊天。 |

新安装默认选「自动（优先直看）」。从旧版升级会沿用原设置，已选识图模型的用户继续「始终转述」，原先关闭识图的用户继续关闭。想体验原图可手动切到「自动（优先直看）」。

- 每条处理前 10 个图片候选附件，可以一次发九张图。直看每条消息合计最多 16 MiB，余下可用的图片有辅助模型时转述，辅助转述每条合计最多 96 MiB。因数量或总大小超限而跳过的图片会在 Discord 提示原图号，可分条重发。支持 PNG、JPEG、WebP，按下载后的文件头识别实际格式。支持私信、允许的频道和讨论串，可只发图或带问题。频道里请 @鲸鲸或回复她的消息。网页链接及被引用消息里的图片不会自动下载。
- 直看每张最多 4 MiB。选择辅助模型后，该模型的单图上限也适用于本条消息，可在「各模型单图上限」单独设置并保存，默认 2 MiB，可设 0.1 至 32 MiB。比如设为 8 MiB，一起发 3、5、9 MiB 三张图时，图1直看，图2转述，图3收到单独的压缩重发提示。未选辅助模型时，自动模式的上限为 4 MiB。模型供应商还可能有自己的输入限制。
- 一张图超限、格式不支持或下载失败，其余可用图片照常处理。提示保留原附件序号；整批下载限时 60 秒。转述默认每轮 120 秒，可设为 30–300 秒。首次转述预算 2000 token，服务返回 `finish_reason: length` 时以 4000 token 再试一次。默认对 DeepSeek Flash 尝试关闭推理，也可选择跟随模型设置。主模型超时、限流或断网不会自动触发辅助转述。
- 直看时，宿主将原图用于本轮对话。使用云端模型时，相应服务会收到图片。插件的 `data/image-receipts/` 收据保存附件序号、声明和检出类型、转述结果及直传图片的校验值，用于处理重复投递；不保存原图。收据保留 30 天。以文字随消息提交的转述会保留在普通会话中。

## 服务器频道命令

在已允许的频道或讨论串输入 `/whale status` 可查看回应状态。`/whale pause` 暂停接收这里的新聊天消息，`/whale resume` 恢复当前位置的回应。更改状态需要 Discord 的「管理频道」权限。命令结果只有操作者可见。暂停按 Bot 和频道或讨论串保存，重启后继续有效。已经开始处理的消息可能仍会回复。

配置了允许频道后，Bot 登录时注册服务器可用的应用命令。若命令列表中找不到它，请检查该应用的安装授权包含 `applications.commands`（通常随 `bot` 一起授予），并确认你在该频道有「使用应用程序命令」权限。Discord 客户端同步可能稍有延迟。控制台的 Discord 设置页会显示注册失败提示；同名命令冲突需要管理者处理。

## 试聊和绑定

- **私信**　用指定账号给 Bot 发「你好」，默认建立独立私信会话。请确保账号能接收该 Bot 的私信，例如已在共同服务器允许私信。
- **网页续聊**　在 WhaleLife 网页对话页选中你要继续的独立网页会话，说一句容易记得的话。在 Discord 插件设置点「查看当前绑定」，核对私信用户、当前绑定和目标会话，再点「绑定此网页会话」。回 Discord 私信问起刚才的话题。绑定固定在确认时的会话，之后切换网页会话不影响私信。要解除共享，在同一处点「新建独立私信会话」，旧历史仍在原会话。
- **频道及讨论串**　在允许的位置发送「@鲸鲸 你想聊什么？」，由 Bot 在原处回复。每条消息保留发言人的 Discord ID 和当时称呼。公开频道及讨论串使用 WhaleLife 独立会话。共享人格设定、宿主全局事实和用户自行开启的其他共享记忆遵循宿主配置。
- **引用回复**　在 Discord 对一条文字消息点「回复」。私信中直接提问；在允许的频道或讨论串中，回复鲸鲸本人时直接提问，回复其他成员时需要直接 @鲸鲸。插件使用 Discord 随这条回复提供的同一位置的原文和作者，最多引用 1500 个 Unicode 码点。引用会作为本次来信的一部分进入会话历史。已删除、只有附件或平台未提供文字的引用会标明原文不可用；此时可以把想问的句子粘贴到消息里。
- **长回复**　每段最多 2000 个 UTF-16 单元。首段引用来信，回复中的文字不会触发用户、角色或全体提及。插件使用宿主回执处理网关重复消息，每段带稳定 nonce。部分已发或发送结果不明时停止后续分段，可在宿主日志中按消息 ID 核对完成状态。
- **范围**　支持文字、引用、频道斜杠命令和可选图片识别。Discord 渠道的模型工具权限固定为关闭。

## 常见情况

| 现象 | 可以检查 |
| --- | --- |
| 设置页一直显示正在连接或登录失败 | 查看最近一次错误码，核对 Bot Token 和运行 WhaleLife 的机器到 Discord 的网络连接，再点「重新连接」 |
| 私信收不到回复 | 检查名单中是否为你本人的用户 ID，以及是否已允许私信 |
| 频道能看到 Bot 却没回复 | 检查是否 @ 到 Bot 或回复 Bot 的消息，并核对频道或讨论串的 ID、可见性和发送权限 |
| 日志显示 generation_failed | 在宿主确认所选人格的模型能完成网页聊天 |
| 提示绑定已改变或会话忙 | 等待正在处理的消息完成，重新预览并核对目标后确认 |

## 源码与测试

`index.ts` 构造 Discord 客户端，`plugin.mjs` 管理其生命周期、宿主渠道和私信绑定，`transport.mjs` 处理事件过滤及投递，`settings.mjs` 提供控制台页面。

将源码和已执行 `npm ci` 的 [WhaleLife 宿主源码](https://github.com/iinukami/whalelife) 放在同级目录，宿主目录名为 `whalelife`。进入插件源码目录运行：

```sh
npm ci --ignore-scripts
npm test
```

可用 `WHALELIFE_TEST_HOST` 指定其他测试宿主目录。测试包含临时 WhaleLife 实例、模拟模型和本机 Discord Gateway/REST 服务。网络测试仅连接回环地址，使用合成凭据。

通过验证的宿主为 v0.1.1、v0.1.2、v0.1.3 和 v0.1.5，Node.js v24.22.3。已覆盖实际宿主加载、配置保存、会话绑定、并发与重启去重、两位发言人、讨论串隔离、长回复部分失败、频道命令权限、暂停状态持久化、图片输入、图片失败处理、识图结果重启去重及真实 SDK 的断线恢复。真实 Discord 账号、服务器权限和投递需在安装后的测试服务器验证。
